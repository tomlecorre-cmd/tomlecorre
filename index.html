Prédiction de Défaut de Crédit & Pipeline MLOps
🎯 Objectif du Projet

Conception d'un pipeline d'apprentissage automatique de bout en bout pour le risque de crédit. L'objectif n'était pas seulement d'entraîner un modèle, mais de prouver la capacité à tracker les expérimentations (MLflow) et à packager l'application web finale dans un environnement isolé (Docker).

🚧 Rigueur & Data Leakage

L'analyse exploratoire (EDA) a révélé des variables biaisées : credit_lines_outstanding (corrélation de 0.86 avec la cible) et total_debt_outstanding (0.75). Ces variables, souvent connues *après* l'octroi du prêt, ont été supprimées du pipeline de preprocessing pour éviter toute fuite de données (Data Leakage) et garantir un modèle robuste en conditions réelles.

⚙️ Tracking MLflow & Modélisation
  • Expérimentations : Benchmark strict entre Régression Logistique (pénalités l1, l2, solver saga), Random Forest (optimisation de la profondeur) et XGBoost.
  • MLflow Backend : Utilisation d'une base de données locale SQLite (mlflow.db) pour enregistrer automatiquement les métriques (Accuracy, Precision, Recall, F1-Score) et les hyperparamètres de chaque run.
🚀 Déploiement Docker & Streamlit

Développement d'un front-end Streamlit à deux facettes : un Leaderboard qui requête directement la base SQLite pour afficher le classement des modèles, et une interface d'Inférence qui utilise le meilleur modèle (XGBoost) pour calculer la probabilité de défaut en direct. Le tout est encapsulé dans une image Docker pour une reproductibilité totale.
